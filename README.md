# Vue Portfolio — Starter Repository

A Vue 3 + Vite learning repository intended for a portfolio. **The current `src/App.vue` still renders the default Vite/Vue starter screen**, so this is not yet a completed personal portfolio.

## Technology
Vue 3 · JavaScript · Vite · Sass · Vue Router

## Run locally
```bash
npm install
npm run dev
```
Run `npm run build` for a production bundle.
